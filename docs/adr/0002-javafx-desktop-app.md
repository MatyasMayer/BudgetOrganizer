# JavaFX desktop app

BudgetOrganizer is a JavaFX desktop application, not a web app (Spring Boot + frontend), a CLI, or an Android app. It stays in one Java/Gradle codebase, and JavaFX includes the pie, bar and line charts the reports need. The cost: no phone access, so expenses can't be logged at the moment of payment. That's acceptable for v1, because the main use is reviewing and planning at a desk.
