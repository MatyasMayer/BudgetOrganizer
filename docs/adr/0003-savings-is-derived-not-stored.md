# Savings is calculated, never stored, and Deficits never reduce it automatically

Savings is recalculated from Transactions every time it's needed: positive Leftovers − From Savings Incomes − Savings-Funded Expenses. Nothing writes month-end "transfer to savings" records, and there are no manual deposits. Past Months stay editable forever, and stored transfers would go stale after every edit. A Deficit does not reduce Savings. It stays flagged until the user adds a Covering Income, so every shortfall needs an explicit explanation.

## Consequences

- An Uncovered Deficit means Savings can show more than the money that really exists. That's a deliberate choice. The dashboard lists every Uncovered Deficit so it can't go unnoticed.
